SAFETY MODEL
  - One-time migration writes only rag_v5_* tables.
  - Existing v4 document_chunks are untouched while RAG_V5_QUERY_ENABLED=0.
  - Query cutover is explicit after `app.rag.v5.diagnostics --strict`.
  - New/reprocessed PDFs after cutover can mirror v5 semantic chunks into legacy
    document_chunks for rollback safety without re-parsing/re-embedding twice.
  - `ROLLBACK_V5/` backups of modified existing source files are created by the installer.
  - Never use `docker compose down -v` for this migration.
