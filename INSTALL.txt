pdfrag Smart Scenario RAG patch
================================

Base repository commit:
89162d856c568141c5863def73377342be3c786c

1. Back up your repo and PostgreSQL database.
2. Extract this ZIP over the pdfrag repository root.
3. Rebuild/start the backend:

   docker compose -f docker-compose.yml -f docker-compose.smart-rag.yml build backend
   docker compose -f docker-compose.yml -f docker-compose.smart-rag.yml up -d backend

4. Backfill smart indexes from your EXISTING chunks (no OCR/rechunk):

   docker compose -f docker-compose.yml -f docker-compose.smart-rag.yml exec backend python -m app.rag.smart_backfill

5. Verify:

   docker compose -f docker-compose.yml -f docker-compose.smart-rag.yml exec backend python -m app.rag.smart_diagnostics

6. Test the real corpus before production use.

Runtime rollback: set SMART_RAG_ENABLED=0 in .env and restart with docker-compose.smart-rag.yml.
Code rollback: restore ROLLBACK/backend/app/main.py as backend/app/main.py.

Read SMART_RAG_PATCH_README.md for behavior, tuning, and safety notes.
